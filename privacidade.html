Política de Privacidade

Ezer.app — Atualizada em setembro de 2026

SOUZA APPS

O Ezer.app foi criado com o propósito de ajudar pessoas a crescerem espiritualmente. Esta política explica de forma clara quais dados coletamos, por que coletamos e como os protegemos.

1. Quem somos

O Ezer.app é desenvolvido por Gabriel Lima de Souza (Souza Apps), desenvolvedor independente com sede no Brasil. Dúvidas: suporte.ezerapp@gmail.com

2. Dados que coletamos

Dados de conta — ao criar sua conta você fornece:

  • Nome e endereço de e-mail (login por e-mail, Google ou Facebook)
  • Foto de perfil (opcional, vinda do provedor de login social)

Dados de uso e engajamento — coletados automaticamente para melhorar o app:

  • Quando você abre ou retorna ao aplicativo
  • Quais séries devocionais você iniciou ou concluiu
  • Quando você cria uma dupla, um grupo ou um jejum

Esses dados são vinculados ao seu ID de usuário, mas nunca ao conteúdo das suas reflexões pessoais ou mensagens de chat.

Conteúdo criado por você — armazenado para que você possa acessá-lo de outros dispositivos:

  • Reflexões pessoais do diário (criptografadas em trânsito)
  • Mensagens de chat em grupos e duplas
  • Propósitos de oração da dupla

Dados técnicos — coletados por serviços de terceiros:

  • Notificações push (Firebase / FCM): token do dispositivo
  • Anúncios (Google AdMob): identificador de publicidade do dispositivo

3. Como usamos os dados

  • Fornecer e melhorar as funcionalidades do app
  • Enviar notificações de lembrete e de atividade da dupla/grupo
  • Analisar quais séries são mais utilizadas (de forma agregada)
  • Exibir anúncios relevantes para usuários do plano gratuito

Não vendemos seus dados a terceiros. Não usamos seus dados para fins de marketing externo.

4. Com quem compartilhamos

  • Supabase — banco de dados e autenticação (servidores em São Paulo, Brasil)
  • Google Firebase — notificações push
  • Google AdMob — publicidade (apenas no plano gratuito)
  • RevenueCat — gestão de compras e plano Pro

Todos os parceiros seguem políticas de privacidade próprias compatíveis com a LGPD.

5. Retenção de dados

  • Dados de uso (app_aberto): mantidos por 90 dias, depois apagados automaticamente
  • Dados de séries iniciadas/concluídas: mantidos indefinidamente para as estatísticas do app
  • Chat e propósitos de duplas encerradas: apagados 24 horas após o encerramento
  • Conta e dados pessoais: mantidos enquanto a conta existir

6. Seus direitos (LGPD)

Você pode a qualquer momento:

  • Acessar os dados que temos sobre você
  • Solicitar a correção de dados incorretos
  • Solicitar a exclusão da sua conta e todos os seus dados
  • Revogar o consentimento para uso dos seus dados

Para exercer esses direitos, entre em contato pelo e-mail suporte.ezerapp@gmail.com.

7. Segurança

Todos os dados são transmitidos com criptografia TLS. O banco de dados utiliza Row Level Security (RLS), garantindo que cada usuário acesse apenas seus próprios dados.

8. Crianças

O Ezer.app não é direcionado a menores de 13 anos. Não coletamos intencionalmente dados de crianças. Se você acredita que um menor forneceu dados sem consentimento dos responsáveis, entre em contato conosco.

9. Alterações nesta política

Podemos atualizar esta política periodicamente. Alterações significativas serão comunicadas dentro do aplicativo. A data de atualização no topo desta página indica a versão em vigor.
